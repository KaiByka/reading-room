O čitaoni

Ovo je osobna biblioteka tekstova i kolumni — mjesto gdje se čuva ono što je vrijedno ponovnog čitanja. Privatna je, bez javne objave, i radi posve lokalno na računalu.

Kako dodati novi tekst

Svaki tekst je jedna Markdown datoteka u mapisrc/content/texts/. Na vrhu datoteke nalazi se kratko zaglavlje s naslovom, opisom, autorom, izvorom, datumom i temama:

---
title: "Naslov kolumne"
description: "Jedna-dvije rečenice o čemu se radi."
author: "Ime autora"
source: "Ime portala ili novina"
date: 2025-01-15
tags: ["kultura", "esej"]
---

Ovdje počinje sam tekst kolumne…

Nakon dodavanja datoteke, tekst se automatski pojavljuje na polici — s pretragom i tagovima. Nije potrebno ništa drugačije.

Pokretanje

  • npm install — prvi put, instalacija
  • npm run dev — lokalno čitanje na localhost:4321
  • npm run build — statička verzija u mapi dist/

Dok je stranica lokalna, potpuno je privatna. Ako je ikada poželiš objaviti, hosting je jednostavan — ali to je drugi razgovor.

Osobna čitaona — tekstovi koje vrijedi pročitati dvaput.
